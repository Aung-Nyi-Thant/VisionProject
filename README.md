# 🎓 Pre-University Portfolio: Multi-Class Computer Vision Digit Classifier

An entry-level Computer Vision pipeline built using **PyTorch** and **Torchvision** to train a Feedforward Neural Network on the classic **MNIST Handwritten Digit Dataset**. This repository demonstrates how a 2D matrix grid of visual pixel data is flattened, processed, and classified into categorical output structures.

---

## 📈 Final Model Performance Metrics
The network was trained for a single baseline epoch (one full pass through the 60,000 image training set) and achieved high generalization accuracy on completely unseen testing samples:

* **Training Examples Evaluated:** 60,000
* **Unseen Validation Examples Evaluated:** 10,000
* **Final Evaluation Accuracy:** 89.28%
